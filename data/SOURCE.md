# Corpus source

`vllm-docs/` is a snapshot of the `docs/` folder of [vllm-project/vllm](https://github.com/vllm-project/vllm)
at release **v0.31.0** (commit `db9527a46873454610df6dbedf79a36d6bf1a7f6`), licensed under Apache-2.0.

Only Markdown pages are included. `contributing/`, `governance/`, `community/` and `mkdocs/` were excluded
as they are not user documentation. The snapshot is committed so that indexing and evaluation are reproducible
offline and in CI.
